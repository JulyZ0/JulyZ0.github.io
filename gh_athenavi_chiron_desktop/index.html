产品能力

四件事，构成一个敢放在本机的 agent。

01

身份绑定 Windows 账户

桌面端不做另一套账号体系。会话身份跟随你登录的 Windows 账户，权限边界与本机一致。

02

执行隔离是默认值

工具执行下沉到受限容器，而不是直接在你的宿主进程里跑。隔离不是可选开关，是启动前提。

03

过程可见

思考、每一次工具调用、本地用量统计、子智能体的运行状态，都能在会话里逐条回看。

04

会话地图与子智能体

长任务拆给子智能体后，仍能在会话地图上看清分支与归属，而不是收进一个黑箱。

执行隔离

沙箱不可用，就不启动。

很多工具在隔离环境准备失败时会静默降级，直接在你的进程内执行命令。Chiron 把这条退路封掉了：检查不通过就终止，并说明原因。你要么在受限容器里跑，要么不跑。

阅读 Windows 隔离方案选型 →
  1. 请求 会话准备调用本地工具
  2. 检查 受限容器是否就绪
  3. 就绪 在容器内执行，过程逐条记录
  4. 未就绪 拒绝启动，不回退到进程内执行

使用场景

适合那些「不想上传，也不想盲跑」的活。

以下为场景示例，用于说明适用范围，不代表实测结果或客户案例。

本机文件批处理

发票、扫描件、日志目录的整理与归档。文件留在本机，执行在受限容器内完成。

仓库排查

跑测试、读堆栈、归并根因。命令在隔离环境里执行，宿主仓库不被顺手改写。

需要交代的长任务

拆成子智能体后仍要能复盘的过程：每一步的输入输出都留痕，便于事后核对。

演示说明

首屏那块界面在演示什么。

切换示例问题会替换对应的执行步骤：归档发票展示计划、容器申请、批量工具调用与子智能体复核；排查失败测试展示容器内执行与根因归并；沙箱不可用展示拒绝启动这条分支。点「重放」可以按顺序再看一遍。
